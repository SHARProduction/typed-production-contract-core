# SHAR Production Contract

A dependency-free typed-data contract library from [SHAR Production](https://sharprod.com/). It provides exactly three operations: deterministic normalization, validation of explicit delivery/rights/scope fields, and version diffing.

```sh
npm install ./production-contract
shar-contract validate contract.json
```

Public source: https://github.com/SHARProduction/typed-production-contract-core. The npm package remains unpublished until npm authentication and clean registry verification pass. MIT licensed.
